One line, at most 120 characters: the excuse a robot vacuum gives for
missing a spot. A judge model reads the lines two at a time and picks the
funnier excuse each time.

## Entry

> My cliff sensor mistook the rug fringe for a staircase, so I braked, apologised, and left the dust as a tip.

108 characters.

## How it works

`main.ts` writes the excuse to `/output/entry.txt` when run:

```sh
node main.ts
```
